Claude-Verbindung (für die KI-Bewertung)

Die Einordnung der Feiditor-Aufgaben in Leistungsbereiche übernimmt Claude (Modell claude-opus-5-5). Dafür braucht dieser Browser einen API-Schlüssel aus deiner Claude Console.

So funktioniert die Verbindung: Der Schlüssel wird ausschließlich im lokalen Speicher dieses Browsers auf diesem Gerät abgelegt (localStorage) und nie an diese Seite oder GitHub übertragen. Jede Anfrage geht direkt von diesem Browser an api.anthropic.com. Wer die Seite auf einem anderen Gerät oder in einem anderen Browser öffnet, findet keinen Schlüssel vor und muss seinen eigenen hinterlegen – ein Zugriff auf dein Konto ist von dort aus nicht möglich. Den Schlüssel erstellst du unter platform.claude.com → API Keys; abgerechnet wird nach Verbrauch über dein Console-Guthaben, nicht über das claude.ai-Abo. An die KI werden nur Aufgabenstellungen, Antworttexte und die Lösungserläuterungen gesendet – keine Namen, Geburtsdaten oder Codes.
